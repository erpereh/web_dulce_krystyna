# Dulce Krystyna — Web Pastelería Artesanal

Sitio web premium para **Dulce Krystyna**, pastelería artesanal en Madrid (Ensanche de Vallecas).

## Stack

- React 18 + TypeScript
- Vite 6 + SWC
- TailwindCSS v4
- Motion v12 (Framer Motion)

## Instalación

```bash
pnpm install
pnpm dev
```

## Scripts

| Comando | Descripción |
|---|---|
| `pnpm dev` | Servidor de desarrollo en localhost:3000 |
| `pnpm build` | Build de producción |
| `pnpm preview` | Preview del build |
| `pnpm lint` | Comprobación ESLint |
| `pnpm type-check` | Comprobación TypeScript |
